# 资产详情预览由 Creation 共用，生命周期保持页面局部

Inspiration Page、Asset Library 与 Creation Workbench 共用 creation Feature 内的 Asset Detail Preview 展示，覆盖侧边栏之外的完整内容区，沿用应用主题和原型布局。各入口继续拥有自己的详情读取、媒体授权、操作能力与关闭生命周期；预览不成为新 Feature，也不把 Workbench 的任务刷新或结果媒体资源提升为全局常驻状态。

生成来源以冻结 Generation Specification 为准，来源任务及同任务结果只在既有授权允许时呈现。共享展示不扩大 Publication 或 Admin 成品读取的窄权限，Reference Material 继续使用各入口已有的授权路径，并保留历史不可用位置。

侧栏在预览期间保持可操作，页面或 Workbench Context 切换关闭预览；返回或 Esc 关闭恢复原页面、滚动位置和打开入口的焦点。底部操作按各入口已有能力呈现，不复制原型中的演示按钮。

打开来源会话的读取、采用会话与请求失效检查由 Creation 的现有导航边界拥有，app 路由只在成功后执行路由跳转。读取期间离开入口、替换 Runtime 或发起新的来源请求会使旧请求失效。

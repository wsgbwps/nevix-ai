根目录作为 monorepo 编排层，通过 `turbo.json` 定义 build/dev/lint 任务依赖，`pnpm-workspace.yaml` 声明 `apps/*` 子包，`go.work` 将 `server/` 纳入 Go workspace。Desktop 与 Server 之间不共享代码，仅通过 `contracts/openapi.yaml` 及按 domain 拆分的 OpenAPI 子文件约定 HTTP 接口；Desktop 内部通过 `apps/desktop/src/shared/ipc/` 的 TypeScript declaration merging 实现类型安全的 IPC 通道注册。数据平面默认由 Desktop 直连 Supabase（Auth/PostgreSQL/Storage/Realtime），Go 仅作为可信执行 seam 处理密钥、支付、Webhook、事务与异步编排。`AGENTS.md` 与 `CONTEXT-MAP.md` 在仓库级统一约束变更审批流程、领域边界与上下文导航，所有子模块必须遵循其目录归属契约。

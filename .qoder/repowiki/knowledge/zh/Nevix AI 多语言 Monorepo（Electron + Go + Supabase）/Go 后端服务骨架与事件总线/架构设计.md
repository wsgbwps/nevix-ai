模块以 `cmd/server/main.go` 为组合根（composition root），仅负责构造依赖并调用各业务模块的 `Register(r chi.Router, bus event.Bus)` 完成路由与事件订阅注册，禁止在 main 中放置业务逻辑或使用 `init()` + blank import。
- `internal/` 存放独立业务 Module，每个 Module 导出 `Register` 方法；简单 Module 放在 `internal/<module>/module.go`，复杂 Module 按 ADR-0003 拆分为 `domain/`、`application/`、`infrastructure/`、`interface/` 四层。
- `pkg/event/` 定义跨 Module 通信的事件总线接口 `Bus`（`Publish` / `Subscribe`）及事件类型 `Event`，所有 Domain Event 类型集中定义在 `pkg/event/types.go`。
- 依赖方向严格单向：`internal/A/` 不得导入 `internal/B/`，模块间仅通过 `pkg/event` 事件总线通信；`pkg/` 仅容纳真正跨模块的基础设施。
- 当前 `go.mod` 声明 module 为 `github.com/nevix-ai/server`，main 程序目前仅注册 `/health` 端点并监听 :8080，其余 `internal/`、`pkg/auth/`、`pkg/database/`、`pkg/middleware/` 目录为空占位。

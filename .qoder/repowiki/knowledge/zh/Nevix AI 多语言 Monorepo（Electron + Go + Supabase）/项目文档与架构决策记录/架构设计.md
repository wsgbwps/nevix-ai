该模块是纯文档目录，按用途划分为三个子目录：
- `adr/`：采用 ADR（Architecture Decision Record）格式，文件以 `NNNN-<slug>.md` 编号命名，记录如 IPC 自注册、Feature Sliced Vertical Slice、DDD 分层、Supabase Go 可信执行等关键架构决策。
- `agents/`：面向 AI Agent / Skills 的领域文档，包括 `domain.md`（指导工程师如何阅读 CONTEXT-MAP、CONTEXT.md 和 ADR）、`issue-tracker.md`（定义 `.scratch/` 下 Markdown Issue 的目录结构、状态行与 triage 标签）、`triage-labels.md`（角色与状态字符串约定）。
- `research/`：预留的研究笔记目录，当前为空。

文档之间通过交叉引用组织：`agents/domain.md` 指向根级 `CONTEXT-MAP.md` 和各 context 下的 `docs/adr/`，形成「全局 ADR → 上下文 ADR → 领域术语」的分层导航结构。

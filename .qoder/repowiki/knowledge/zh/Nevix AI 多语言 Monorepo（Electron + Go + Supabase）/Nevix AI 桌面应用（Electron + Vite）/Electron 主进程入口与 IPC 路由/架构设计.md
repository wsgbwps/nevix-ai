模块以 `index.ts` 为 Electron 主进程入口，通过 `import.meta.glob('./ipc/*/index.ts', { eager: true })` 自动发现并调用每个子目录的 `register()` 函数完成 IPC 路由注册，形成插件式扩展点。
- `ipc/` 按领域划分（authentication、i18n、settings），每个子目录提供 `index.ts` 暴露 `register()`，内部再拆出 handlers 文件，命名遵循 `<action>:<channel>` 的通道约定（如 `authentication:read-session`）。
- `authentication/session-store.ts` 使用 Electron `safeStorage` 对会话进行加密持久化，采用 pending 文件 + rename 原子写入，失败时回滚；`settings/language-mode-store.ts` 以 JSON 文件持久化语言模式。
- `window/main-window.ts` 负责创建唯一 BrowserWindow，启用 sandbox、contextIsolation、nodeIntegration:false 等安全选项，并通过 preload 脚本桥接渲染进程。
- `i18n/index.ts` 基于 i18next 初始化主进程国际化，从 `language-mode-store` 读取语言模式并结合系统语言确定界面语言，同时导出 `getMainWindowTitle` 供窗口标题使用。
- 依赖方向单向：IPC handlers → store/i18n → Electron API，不反向依赖 window 或 ipc。

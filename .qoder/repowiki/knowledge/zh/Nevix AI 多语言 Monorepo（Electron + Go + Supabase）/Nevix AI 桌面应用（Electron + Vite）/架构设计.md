本模块以 `electron-vite` 为构建中枢，同时编译 main、preload、renderer 三个入口，并通过 `src/shared/` 目录中的 TypeScript 类型文件作为跨进程契约：
- 主进程（`src/main/`）负责初始化 i18n、注册各模块 IPC 处理器、创建受 CSP 保护的 BrowserWindow，并持久化会话与语言模式设置。
- 预加载脚本（`src/preload/`）仅暴露安全桥接 API，屏蔽 Node.js 直接访问。
- 渲染进程（`src/renderer/src/`）是 React 应用，由 `main.tsx` 引导 i18n 与 Providers，根据认证状态路由到认证界面或主界面。
- 共享层（`src/shared/`）集中定义 Supabase 公开配置解析、i18next 选项、IPC 通道与消息类型，被主进程与渲染进程共同引用。
- 构建期通过 `electron.vite.config.ts` 注入 Supabase URL、Key 与策略，并替换 HTML 中的 CSP connect-src 占位符。
- E2E 测试（`tests/`）使用 Playwright 启动真实 Electron 实例，配合本地 Supabase 模拟服务验证认证边界、会话持久化与 i18n 行为。

- 国际化资源通过 `defineResourceTranslations` 与 `ResourceOwner` 类型在 `shared/i18n/resource-contract` 中统一定义，各模块按命名空间（如 `app`、`authentication`、`settings`）导出 `resources` 对象供 renderer 聚合。
- 跨进程通信统一通过 `window.api.invoke(...)` 发起请求、`window.api.on(...)` 订阅事件，避免直接依赖 Electron API。
- React 应用启动采用异步 `bootstrap` 函数模式：先完成外部初始化（如 i18n），再调用 `createRoot().render()` 挂载树。
- 全局样式集中在 `globals.css`，通过 `@import` 引入 Tailwind、shadcn 与字体，并使用 CSS 变量 + `:root` / `.dark` 双主题覆盖实现明暗模式。

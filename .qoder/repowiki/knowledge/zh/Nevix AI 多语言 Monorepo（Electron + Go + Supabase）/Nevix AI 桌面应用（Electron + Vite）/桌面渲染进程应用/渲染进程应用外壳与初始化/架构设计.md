模块以 `index.html` 为 Electron 渲染进程页面入口，通过 `<script type="module" src="/src/main.tsx">` 加载 React 应用。`main.tsx` 作为异步 bootstrap：先通过 `window.api.invoke('i18n:get-bootstrap')` 从主进程获取初始语言与环境配置，调用 `initializeRendererI18n` 初始化 i18next 实例，并监听 `settings:language-mode-changed` IPC 事件动态切换语言；随后用 `createRoot` 挂载 `<StrictMode><Providers><App /></Providers></StrictMode>`。`providers.tsx` 仅暴露 `I18nextProvider` 包裹 i18n 实例。`App.tsx` 是根 UI 组件，基于 `useAuthentication()` 的状态决定渲染 `AuthenticationScreen` 或主界面，并通过 `LanguageModeSettings` 提供语言切换。`i18n/` 子目录集中管理国际化：`renderer-i18n.ts` 聚合 `appResources`、`authenticationResources`、`settingsResources` 构建 renderer 侧资源，`index.ts` 使用 `defineResourceTranslations` 和 `ResourceOwner` 类型定义 app 命名空间翻译，所有翻译均通过共享的 `shared/i18n/resource-contract` 契约保证类型安全。样式由 `globals.css` 统一引入 Tailwind、shadcn/tailwind.css 与 DM Sans 字体变量，并定义 light/dark 两套 CSS 变量主题。依赖方向单向向下：`main.tsx → providers → App → features/*`，i18n 通过共享契约与 IPC 与主进程解耦。

该模块采用按 feature 划分的目录结构：`index.ts` 作为统一导出入口，暴露 i18n 资源（`settingsResourceOwner`、`settingsResources`）和 UI 组件；`i18n.ts` 使用 `defineResourceTranslations` 定义中英双语翻译资源，并通过 `ResourceOwner` 类型注册到共享的 i18n 系统中；`ui/language-mode-settings.tsx` 是纯 React 组件，通过 `window.api.invoke` 调用主进程的 `settings:get-language-mode`/`settings:set-language-mode` 接口，并订阅 `settings:language-mode-changed` 事件实现响应式更新。依赖方向单向：UI 组件 → shared/i18n 类型定义，不反向依赖上层路由或状态管理。

- 每个功能域在 Desktop 的 `features/`、`shared/ipc/<domain>/` 与 `main/ipc/<domain>/` 三处保持同名目录对应，形成垂直切片
- IPC 类型通过 `declare module '@ipc/channels'` 在各 domain 内扩展 IpcChannelMap/IpcEventMap，禁止修改共享基座文件
- Go 后端每个 module 暴露 Register(r chi.Router, bus event.Bus) 接口，由 cmd/server/main.go 显式组装
- OpenAPI 契约按 domain 拆分独立 yaml 文件，由 openapi.yaml 通过 $ref 引用聚合
- 变更必须首先确定 primary Domain 与最窄拥有边界，跨共享区域或 trusted-execution seam 的改动需维护者审批

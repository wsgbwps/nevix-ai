- 每个技能目录必须包含 SKILL.md（front matter 中声明 name/description/disable-model-invocation）和 agents/openai.yaml（interface.display_name + policy.allow_implicit_invocation）两个文件。
- SKILL.md 采用 front matter + Markdown 正文的结构，步骤按顺序编号，每个步骤以可检查的 completion criterion 结尾。
- 长内容通过 context pointer 引用外部 .md 文件（如 GLOSSARY.md、tests.md、mocking.md）实现渐进式披露，避免 SKILL.md 膨胀。
- router 类技能（如 ask-matt）通过斜杠路径名（/skill-name）引用其他技能，形成明确的主流程与 on-ramp 分层。
- 需要持久化状态的技能使用 CONTEXT.md 记录领域语言与决策，配合 ADR 格式保存不可逆决定。
- 对外部工具的调用先通过 --help 或官方文档发现命令，禁止猜测参数或硬编码版本。

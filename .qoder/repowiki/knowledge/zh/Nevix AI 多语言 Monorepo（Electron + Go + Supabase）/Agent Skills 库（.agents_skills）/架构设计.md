每个技能是一个独立目录，遵循统一结构：SKILL.md 定义名称、描述、可选的 disable-model-invocation/metadata front matter 以及步骤与参考内容；agents/openai.yaml 声明 display_name、short_description 和 policy（如 allow_implicit_invocation: false）。部分技能还包含 scripts/、assets/、references/ 等子目录存放模板、外部引用或参考资料。ask-matt 作为路由器技能，将用户意图映射到主流程（grill-with-docs → handoff/prototype → to-spec → to-tickets → implement → code-review），并串联 triage、diagnosing-bugs、wayfinder 等入口。技能之间通过 /handoff 在会话间传递上下文，通过 /compact 在同会话内压缩历史。supabase 和 supabase-postgres-best-practices 是纯参考型技能，不依赖 agents/openai.yaml，而是通过 references/ 目录组织主题文档。整体无运行时代码，全部由 SKILL.md 驱动 Agent 执行。

### 可信执行 seam
- 定义：指从桌面客户端进入 Go 后端的受信任操作边界，仅用于处理密钥管理、额度/支付、Webhook、管理员权限、数据库事务或异步编排等需要更高权限的操作。普通 CRUD 操作由桌面端直接使用 Supabase 完成，不经过此边界。
- 别名：trusted-execution seam、seam

### 垂直切分
- 定义：项目采用的架构组织方式，按功能领域将代码物理隔离，每个开发者负责一个完整的 Feature 目录，包含 UI、IPC 类型、主进程 handler 和相关测试，避免横向共享层的过度耦合。
- 别名：vertical slice、Feature-Sliced

### IPC Channel
- 定义：Electron 主进程与渲染进程之间的类型安全通信通道，采用 declaration merging 机制在各 domain 中独立扩展 IpcChannelMap/IpcEventMap，通过 path alias @ipc/channels 引用而非相对路径。
- 别名：IPC channel、channel

### Domain Event
- 定义：Go 后端模块间通信的事件类型，统一定义在 pkg/event/types.go 中，模块通过事件总线进行解耦通信，禁止 internal/A 直接 import internal/B。
- 别名：domain event、event bus

### Composition Root
- 定义：应用的组装入口点，如 apps/desktop/src/main/index.ts、server/cmd/server/main.go，只负责依赖注入和模块注册，不包含任何业务逻辑。
- 别名：composition root、entry point

### Shared Area
- 定义：仓库中需要维护者审批的共享代码区域，包括 apps/desktop/src/renderer/src/components/ui/、lib/、hooks/、server/pkg/ 和根目录 contracts/，变更需要明确影响分析和测试覆盖。
- 别名：shared area、shared code
